# Como navegar no repositório

Pode ignorar os arquivos que estão fora de qualquer subdiretório.

## src
Todo o código "base", feito apenas usando Numpy e Scipy: implementação do modelo de regressão linear, funções estatísticas, etc;
### models
Arquivos relacionados ao modelo de regressão linear
### stats
Arquivos relacionados às funções estatísticas
### plots
Apenas definindo o tema visual dos gráficos

## scripts
Os scripts relacionados a cada fase do projeto. Idealmente seriam notebooks Jupyter, mas meu Linux sempre buga pra carregar o kernel Python lá, então preferi usar scripts mesmo.

## reports
Relatórios textuais e gráficos de cada etapa do projeto.
